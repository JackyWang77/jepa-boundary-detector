## 2 τ 度量学（§2 核心，最需精写的一节）

- 定义：τ = 截断自相关积分（估计量 A，初正序列截断）；模型侧 τ_B = −1/log|λ|（Jacobian 谱）
- 与谱映射/Koopman 社区标准变换同构（引 Spectral Maps, arXiv 2311.16411）；行为学同族（arXiv 2605.24135）
- **四条可信性保障**：
  1. 双估计量交叉验证（A/B 独立，e2jepa：动力学谱 0.14-19.6 连续 vs 坐标全维 9±1 ——动力学学到多尺度、坐标系不继承）
  2. 外部真值校准（LeWM 7 个中性模态 = PR 6.2 = PushT 物理内禀维，积分器签名）
  3. 自曝失效机制（energy_only 伪慢 τ=15.6：常数信号信息为零——τ 只在 S>0 时有定义，自由能形式是存在性前提）
  4. 合成信号校准（AR(1) 真实片段长度分布：真 2/5/10/22/40 → 测 2.7/4.8/7.2/10.8/12.9，单调鲁棒、大 τ 压缩有界；报告绝对值附校准曲线）
- E3 任务谱 ground truth：τ_block≈22.3-23.1 / τ_agent≈13.2-13.9 / 速度层 ~2（block 仅 2.6% 时间在动；dwell 中位 16 步；stroke 中位 17 步；stroke 分割=免费真值）
- 工程附录：块追踪刚性模型（质心=block_pose+R(θ)·(0,40.7)，残差 0.54px）；probe 对齐验证（agent 双判别器 5× 分离）

## 4 审计结果：五模型全败（§4 核心）

- 主表：e2jepa / tv / jepa / energy_only / LeWM（官方）× H3a/H3b/H4/H5
  - H3a 全败：e2jepa top8=0.17≈随机 0.16（涂抹端）；LeWM 0.37 vs 随机 0.30（压缩端：τ 同质化 1.37×+低 SNR）——**两端死路都败于 H3a 但机制不同**（两头堵死的 H-量化）
  - H4 全败：ε* ratio 0.82-0.98（K=2..5）；本征矢 IPR 2-4× uniform 但无块
  - H5 全败：h*=11/15/18/25；slow-proj rollout h=4 即死；err(32)>1.0 主动发散
  - **单-stride 自然实验**：LeWM macro-5 头 h*=25 > stride-1 各臂——stride 买跟踪（A3 方向性外部实证）但单尺度不够（dwell 区 0.70 崩）、且不沉淀进坐标（H4 败+proj 死）
  - **误差复合压倒信息**：LeWM direct 0.28@20 步 vs 迭代 0.70；e2jepa 0.87 vs 1.18@16——慢内容本身可预测，是迭代毁了它

## 5 机制分析：强制力的两通路与关闭其一

- 两通路枚举（答辩完备性）：无内容监督下梯度只能通过"内容对 loss 的贡献"了解内容 → 可耦合时间尺度的自由度仅两处：**率**（A4，量）与**任务形状**（A3，方向）；架构=地形（不给方向）；数据频率按帧粒度无法分离同帧内容；独立正则内容置换对称；显式监督被"自动"排除（定义域）
- **定理级支撑**（引 H-JEPA 附录 L 作 P0）：命题 1（边际正则不可排除零损失解——SIGReg/熵项皆边际）+ 定理 1（目标按可预测性选择；动作封闭分量免费编码）
- 通路一关闭（双实验）：
  - v1 温度矢量（分配）：判据三败，方向全对——温度控制"存活"不控制"落位"
  - E1 率消融（总量）：t_max 0.03→3.0，block 0.825→0.730 反降、agent 平（0.31-0.35）、PR 79→119——**预算买维度不买组织**；P1b/P1c 如实记 FAIL
  - **E1 新发现（独立可引用）**：信息取舍的真正轴是"是否已被动作决定"，时间尺度是混淆变量（agent 内容被动作条件化掩护；旁证：LeWM weak-policy 随机动作下 agent probe 0.69 vs 我们 teleop 0.35）
- 通路二 = 唯一幸存 → 组织层设计（§6）

    - **新增 insight：scalar ρ 是 16 维本征模数谱的有损压缩**（从 D14→D17 的完整链条看出来的）：P4 的主本征模数 ≈ 1.0 是 persistent data LS 解的自然属性（数据长期记忆性）；当共形族的 ρ 冻结到 ≈1（或者 learnable ρ 被推到 1），`ρ^s × expm(sΩ) ≈ expm(sΩ)`（纯旋转），而纯旋转相对误差 `||e^{sΩ}x - x||/||x|| ≈ sΩx/x ≈ sΩ` 可以极小——U 就"饱和"了，不需要任何真正的衰减。这解释了 D14 的坍缩、D17-with-frozen-P4-rho 的同样坍缩、以及为什么 scaffold rho_init 系统性偏慢（cross-cov ratio ≤ 谱半径——把 16 个模数压成 1 个的副作用）。
    - **scaffold rho_init 偏慢的判决性证据**：PushT fast band scaffold=0.84 vs P4=0.95（差 0.11），AntMaze fast band 0.666 vs 0.964（差 0.30）。scaffold 测量偏慢 → v1.4 训练的动力学偏保守 → fast band 的真实衰减被低估。但即使 scaffold rho_init 正确，共形族的结构限制（所有本征模数共享同一个 ρ）仍然是有损的——这就是 L2 说的 "LS 解更好" 的结构原因。
- 相位分段合法性：action 是输入流非状态标签（与 IDM 同级合法）

## 7 Discussion

- 与 H-JEPA 的精确关系：机制验证（他们 §3 谱质心独立互证我们 A3+E3）+ 定理背书（附录 L ↔ 我们 E1）+ 空位确认（他们无判据/无验收阈值/无失败预测）
- 与 Iso-Dream/IFactor：动作决定性轴的架构侧文献群（我们提供率消融的测量证明）
- 局限（诚实）：小底座上充分性未达（三次 τ 微分均 <1.2 vs 判据 2.5）；判据通过性待大底座验证（B1）；PushT 谱温和是困难任务不是方法失败（可预测）；**C1 已退役（§6 加权定理：`pooled dispR2 = Σ w_k R²_k` 且 `w_k ∝ 1/τ_k`，名义阶梯的 OU 最优 pooled = 0.21 < 0.37，阈值对任何多尺度表征不可达；替换为逐带效率 C1\\*（每带 vs 自身 OU 上限，AntMaze ≥0.96）与无量纲时钟律 h/τ（比值 ≤1.53，h≈2τ 坍缩极差 0.006-0.068），两者三底座基本通过）**；作为历史记录保留 C1 的机制分解（§6）：PushT 上是编码器噪声地板（stride-1 增量 ceiling 0.137，判据阈值物理不可达，需 stride 参照化），AntMaze 上是坐标曲率（增量 75-80% 可预测但非线性）——D5b 判决（§6，三步预注册）将损失精确定位（SNR 稀释否证；AntMaze 失在冻结 SFA 脚手架层=慢通滤波器不张成切空间；PushT 失在训练层），**v1.3 切空间修复（§6）已实施并复测**：相空间脚手架（q+q̇）+ 切空间 coverage 使 AntMaze 两底座 C1 大幅逼近阈值（0.314/0.354 vs 0.37，H-JEPA 差 0.016 未中如实记）、切空间内容 lin(x→dz) 恢复至 PCA 上限水平（LeWM 0.027→0.315、H-JEPA 0.237→0.445）、H-JEPA C3 反翻 PASS、全数据集无 PASS→FAIL 翻转，自由能训练从"丢内容"转为"保内容"；残存项：PushT 逐带效率带0 卡在噪声地板（R² 0.004 vs 上限 0.010，η=0.39）、LeWM null 0.315 边界违反（AntMaze 两 null 骑 0.3 边界，slow-xy 机制，动力学贡献须用 Δseg 分离）；W_DCOV 权重 amendment 不再推荐——C1 已退役，该杠杆瞄准的是一个不该被优化的量；**判决性实验（§6）已将"慢带垄断"从失败模式中移除：分配力非 winner-take-all，内容按时间尺度落位的 law 在 v1.3 首次带内容显形（速度居最快带 0.21-0.31，位姿居最慢带 0.82-0.86）**
- 远景：判据学作为 JEPA 预训练的标准审计协议（"τ-lint"：任何新 JEPA 底座先跑 H-标准）
- 新增局限（D11-D14，诚实）：**时钟的三种含义不可混用**——(1) 数据的衰减率（谱量，cross-cov 比可测）；(2) 预测最优的乘性系数（shrinkage，混合了信噪比）；(3) 内容的时间常数（τ_eff vs E3 GT）。D11 证明 (1) 的传播子在 forecast 口径不如冻结坐标、但在 ensemble 口径把 PushT block 的 τ 校准到 GT 的 0.7%；D13 证明 (1) 的正确估计量是条件均值而非能量比；D14 证明 **(2) 不能用梯度学**（可学习 ρ 被 U 买到两端极值，慢带→持久、噪声带→塌到 τ≈1，τ_eff 反而过慢 2-3×，PC 上 C4 直接失败）。因此本工作对"时钟"的主张只到"可测且 ensemble 校准"为止，不主张"可学"。另：**D14-4 型判据（我们的 rollout ≥0.9×冻结坐标）是闭包判据**——identity 即可满足，今后凡涉及内容预测的判据必须配对信息性判据（τ 校准误差 |ln(τ_eff/τ_GT)|、逐带效率 C1\\*）一起报。
- 新增局限（D9，诚实）：**每带的 τ 是 lag-1 有效值，不是单一指数常数**——半群在算子级成立（H 中位数 ≤0.17），但逐步衰减随 horizon 漂移（快带最多 90%），块内存在衰减率宽度，长 horizon 表观 τ 变长。因此任何用 τ 做的无量纲标度（时钟律、h/τ 规划预算）必须声明所取的 horizon；29 与 40 都可能是同一带的"真 τ"。另：**PushT 的切线半幅不是 OU**——增量 PCA 方向靠随机游走式非平稳漂移获得增量能量（实测 lag-1 相关 0.975，τ 39-69），脚手架却声明 τ 0.48-1.94，导致冻结 ρ 与真实坐标不一致（学习传播子 s=1 位移 R² −2.49 → 换成实测 ρ 后 0.057）。这是 measure-then-learn 的一个具体不诚实处（继承了 q 的模数去描述 q̇），已作为下一个最小修复登记。
- **三条时间尺度定律（D14→D15→D16 闭合）**：
  1. **L1：时钟不可学，只能测**（D14）。ρ 作为预测损失的乘性系数买到的是 shrinkage 系数，不是衰减率。U 无法区分"真衰减"与"不可预测"，因为它看不到无噪声的衰减；learnable ρ 被推到 1（慢带）或 τ≈1（快带），两端极值。这是 measure-then-learn 的精确边界——坐标（自由能）可学，时钟（谱量）不可学。
  2. **L2：测量动力学就是最小二乘解**（D16）。P4 = argmin_M Σ ||x_{t+1}^{(k)} - x_t^{(k)} @ M||²（每个 16 维块独立拟合的全算子）在 pooled RMSE 上永远胜 identity（18-30%）、永远胜任何结构化受限族（k-mode、共形族 P3 等）。之前"结构要刚好够"是 instrument bleed（内容时钟 τ_host 滑出观测范围的误判），不是动力学本身的 tradeoff。**D17（§6）把 L2 从零重训验证升级为训练内部闭环**：将冻结的 P4 算子直接作为训练传播子（零可学动力学参数），三底座判决判据除时钟翻转（hjepa C3，归因于下述三时钟矛盾而非动力学本身）外无一失守（E-d17-2 C4 3/3，U 无塌缩 0.179/0.386/0.231）。
  3. **L3：坐标质量是一切动力学的上限**（D16）。D14 的 learnable ρ 把坐标质量退化 2–5×（v1.4 → v1.5：PushT 1.8×、LeWM 3.7×、H-JEPA 4.2×），任何动力学都受害，但 P4 受害最小（从 0.0055→0.0097 仍保持最优）。真正的动力学贡献（Δseg = 0.17–0.21）在 v1.5 没有丢失——丢失的是坐标的可预测结构本身。
  这三条构成一个简洁的物理图景：**JEPA 潜空间的时间演化是线性的（P4 即 LS 解），其可预测程度由坐标的质量决定；坐标可以学，时钟（衰减率）不行；而动力学的预测器不需要任何特殊结构，只要你愿意相信最小二乘**。极简主义者会说："测量就是一切。"
