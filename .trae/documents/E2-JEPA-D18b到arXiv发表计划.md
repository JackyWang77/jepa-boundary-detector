## 0. 贡献定位（钉死：我们做的不是"发明一个判断器"）

**判据是仪器，不是贡献。** 论文的 headline 是仪器看到的东西，四层结构：

1. **现象（首报）**：潜空间时间尺度谱无隙——六个模型、两个实验室、四类目标函数、
   两类防塌缩，分层从不自发出现（六次复证）。
2. **定律**（论文核心）：
   - L1 时钟不可学只能测（ρ 是 shrinkage 不是衰减率，D14）
   - L2 测量动力学就是最小二乘解（P4 永远胜任何结构族，D15→D17 训练内闭环）
   - L3 坐标质量是一切动力学的上限（可学 ρ 把坐标退 2-5×，D16）
   - 落位律：内容按自身时间尺度落位，慢带垄断=持续性变量的正确热力学平衡（D1-D3）
   - **三时钟恒等式**：设计时钟（SFA 模数）≠ 测量时钟（P4 谱半径，近积分污染）
     ≠ 内容时钟（E3 真值 23.0/9.13）——设计阶梯系统性高估内容时钟 2.5-11×
     （D18），混淆三个时钟是一切分层方案缺陷的根。
3. **机制**（为什么不自发）：边际正则定理级地看不见跨时间联合分布（H-JEPA
   定理 1 互证）；率不买组织（E1 双消融）、温度不控落位（v1 三败）、任务形状
   是唯一幸存强制通路（A3 存在性首次受控证据）；数据谱分离决定可行性
   （AntMaze vs PushT，事前预测公开应验）。
4. **配方**（最小修复）：measure-then-learn——相空间脚手架 (q,q̇)（Koopman
   坐标必须张成相空间）+ 冻结测量动力学（L2）+ **内容校准 banding**（D18b
   是闭环的最后一环：把 banding 目标从 SFA 模数换成内容时钟）。

**完成定义（验收）**：D18b 判决落盘归档；LaTeX 全文（Abstract→附录）图表齐全；
verify.py 13/13 复跑通过；每个数字有 JSON 落盘、每个负结果如实记录。

**对改进 H-JEPA 式系统的直接意义**（论文 so-what，量化而非定性）：
1. **验收协议**：任何分层世界模型必须过 H-标准（谱有隙、慢维载慢内容、
   可装配）——否则分不清真分层还是手放层级（后者实测只产生 ~1.5×/层的
   平凡 τ 漂移，已两次判决）。
2. **失败边界**（事前可测）：数据谱分离弱（PushT 类操作任务）→ 分层难产
   且架构救不了；谱分离强（AntMaze 类）→ 可行。事前预测已公开应验。
3. **最小配方**：时钟测出来不是学出来（L1）+ 动力学冻结在 LS 解（L2）+
   banding 编码内容时钟而非 SFA 模数（三时钟恒等式）——D18b 钉死第三条。
4. **互证**：H-JEPA 定理 1（边际正则不可排除零损失解）在 E1 拿到首个测量级
   实证；反过来审计显示底座本身不自发分层 → 改进路径 = 冻结底座 + 组织层
   post-training 适配器（我们配方的定位），不是调架构。
论文性质：定量测量学 + 定律 + 配方（"Balmer 测准光谱，Bohr 才有靶子"），
不是定性评论。

**关键区分：功能分工 ≠ 结构分层**（审稿人必问"H-JEPA 显示高层忽视移动
障碍，这不是分层吗？"——论文必须有专门一节，是防御也是贡献）：
- H-JEPA 的证据是**功能**（rollout 行为分工）；我们的审计测的是**结构**
  （谱分簇、慢维载慢内容、可装配）。两者可同时为真。
- 功能分工的来源恰是我们的 A3 幸存通路（任务形状压力），不是架构自组织
  的功劳——E1/v1 闭合两通路后这是唯一强制通路，AntMaze 谱分离强所以它出现。
- 最干净的对照已落盘：LeWM macro-5 单-stride 自然实验——stride 买到跟踪
  （h*=25 > stride-1 的 11-18）但**不沉淀进坐标**（H4 败 + slow-proj 死）。
- 生死攸关的物理理由：高层混有快内容 → 有效信任视界由层里最快的内容决定，
  不由名义 stride 决定 → 迭代误差照样复合（H5：err(32)>1 主动发散）。
- 反转：H-JEPA 自己的 Theorem 1 说边际正则不可排除"只编码背景"的零损失解
  ——"高层忽视移动障碍"正是该简并解族的签名；区分真慢内容 vs 静态背景
  需要我们的探针（H2/C2），E1 已给出首个测量级实证。
- 结构上 H-JEPA/LeWM 底座实测：每层谱跨两个数量级连续（max gap 1.37）、
  τ 漂移仅 1.5-1.7×/层（设计意图 {5,10,20}）、H4 败——功能有、结构无。

**够与不够（诚实）**：对 arXiv + 会议 + 博士申请，上述组合完整且稀缺（首报现象 +
定律 + 定理级机制 + 配方 + 预注册纪律）。更强有两条路——大底座复验（B1）、下游
规划提升——写进 Discussion future work，不进本次 scope。
